# Changelog

## 1.0.0

Initial release.

- **New Roblox Script...** command in the explorer context menu and the Command Palette
- Server, client and module scripts with Rojo file extensions (`.server.luau`, `.client.luau`, `.luau`)
- Configurable templates per script type with a `{name}` placeholder
- Script names are validated as Luau identifiers
- `firstPrompt` setting to ask for the type or the name first
- Existing files are never overwritten
